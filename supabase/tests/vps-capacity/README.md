# Retired pre-component capacity harness

The former harness wrote the retired truck, purchase-line, wallet and Filled/Empty backend formats. Its executable entry points have been removed rather than retaining compatibility branches or allowing a stale benchmark to mutate the current schema. Original source and measured results remain at their historical Git boundary and in ignored evidence; no generated manifests, credentials or retained businesses are deleted by this cleanup.

Current correctness checks are listed in [the acceptance catalog](../README.md). Current volume-audit evidence is separate from sustained capacity proof. A new capacity benchmark must use canonical Gas/Bottle/Unit acquisitions, real authenticated sessions and current source-linked payment/transport operations; no current capacity limit is claimed from the retired workload.
